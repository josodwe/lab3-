# МеховаАС_СПиМП_лаб3

## Лабораторная работа №3

**Тема:** Консольная игра «Виселица» на языке Rust.

## Описание проекта

Проект представляет собой простую консольную игру «Виселица».  
Программа случайно выбирает слово из списка, а пользователь должен угадать его, вводя буквы по одной.

Если буква есть в слове, она открывается.  
Если буквы нет, количество ошибок увеличивается.  
После 6 ошибок игрок проигрывает.

## Что используется в проекте

- язык программирования Rust;
- ввод данных через консоль;
- циклы `loop`;
- условные операторы `if`;
- конструкция `match`;
- коллекции `Vec` и `HashSet`;
- библиотека `rand` для случайного выбора слова.

## Как запустить

В папке проекта выполнить команду:

```bash
cargo run
```

## Краткое пояснение логики

1. Создается список слов.
2. Программа случайно выбирает одно слово.
3. Пользователь вводит буквы.
4. Программа проверяет, есть ли буква в слове.
5. Если слово полностью угадано — победа.
6. Если ошибок стало 6 — поражение.

## Ответы на вопросы

### 1. Как организовать логику игры?

Логика игры организована через главный цикл `loop`. Внутри цикла программа показывает состояние игры, считывает букву, проверяет ее и обновляет количество ошибок или список угаданных букв.

### 2. Что такое итераторы и как их использовать для перебора слов?

Итераторы позволяют последовательно проходить по элементам коллекции или строки. В проекте используется перебор символов слова через `secret_word.chars()`.

### 3. Как обрабатывать ввод пользователя в консоли?

Для ввода используется `std::io::stdin().read_line()`. После ввода строка очищается методом `trim()` и переводится в нижний регистр методом `to_lowercase()`.

### 4. Как можно использовать `match` для организации игрового состояния?

В проекте `match` используется для выбора рисунка виселицы в зависимости от количества ошибок. Для каждого значения ошибок выводится свой вариант рисунка.

### 5. Как проверять и фильтровать пользовательский ввод?

Проверяется, что пользователь ввел ровно один символ и что этот символ является английской буквой. Если ввод неправильный, программа просит ввести букву заново.
